# 영양성분 원료 형태(기원) 검색 — 검증 자료

공장 사용성 검증 피드백 중 **"영양성분 주원료도 혼합제제·건조효모 등으로 나뉘는데 그것도
검색되면 좋겠다"** 를 구현한 결과다. 배포 전에 연구원이 확인해야 하는 판정 규칙과, 원본
데이터 45,996건 전체에 돌린 실측 분포를 함께 적는다.

다시 뽑는 방법:

```bash
node scripts/verify-ingredient-source.mjs
```

판정 코드는 [`src/lib/ingredientSource.ts`](../src/lib/ingredientSource.ts), 규칙을 고정한
테스트는 [`tests/ingredientSource.test.cjs`](../tests/ingredientSource.test.cjs) 다.

---

## 1. 근거와 범위

판정의 근거는 품목제조보고의 **원재료명(`RAWMTRL_NM`) 표기 하나뿐**이다. 이 앱의 값은
전부 식약처 공개 자료로 되짚을 수 있다는 데서 신뢰를 얻으므로, 표기에 없는 정보는
추정해서 채우지 않는다.

그래서 다루는 것과 다루지 않는 것이 갈린다.

- **다룬다** — 원재료명에 적힌 원료 이름에서 읽어낼 수 있는 것: 어떤 영양성분인지, 어떤
  염·형태인지, 혼합제제·유지 제제인지, 효모 배양물인지
- **다루지 않는다** — 원산지(국가). 원재료명 칸에 그 정보가 없다(45,996건 중 국가명이
  보이는 행이 100건 미만이고 그마저 원료 원산지를 가리키는 문구가 아니다). 표기에 없는
  값을 사람이 채워 넣으면 나머지 수치의 근거까지 흐려진다

화면의 `기원`(효모 유래 / 천연물 유래 / 화학합성)은 **원료를 무엇에서 얻었는지**를 뜻하며
원산지 국가가 아니다. 오해하기 쉬운 표현이라 조건 아래에 그 문장을 적어 두었다.

## 2. 판정하는 네 축

| 축 | 뜻 | 값 |
|---|---|---|
| `nutrient` | 어떤 영양성분의 원료인가 | 아연, 비타민D, 셀레늄 … 25종 |
| `form` | 구체적으로 어떤 형태인가 | 산화아연, 건조효모(아연), 비타민D3(콜레칼시페롤) · 혼합제제 … |
| `origin` | 무엇에서 얻었는가 | 효모 유래 / 천연물 유래 / 화학합성 / 형태 미표기 |
| `prep` | 어떤 제제로 만들어 왔는가 | 혼합제제 / 유지(Oil) / 분말·과립 / 원말 |

`origin` 과 `prep` 은 독립이다. `비타민 D3 혼합제제유지` 는 화학합성 + 유지 제제고,
`건조효모(비타민D)` 는 효모 유래 + 원말이다.

형태 이름에는 혼합제제·유지만 꼬리표로 붙인다(`· 혼합제제`). 분말·과립은 순품의 물리
형태일 뿐이라 따로 가르면 목록만 늘어난다.

### 표기 흔들림 흡수

원본 표기가 심하게 흔들린다. 공백·하이픈·괄호·`(고시형)` 표식·그리스문자를 지운 문자열로
비교해서 아래를 모두 한 형태로 모은다.

| 원본 표기 | 판정 |
|---|---|
| 비타민D3혼합제제 / 비타민 D3 혼합제제분말 / 분말비타민D3혼합제제 / 비타민 D3 혼합제제유지 | 비타민D3(콜레칼시페롤) · 혼합제제 |
| 건조효모(셀렌함유) / 셀레늄함유건조효모 / 식용건조효모(셀렌으로서 0.1%) / 효모((셀렌)) | 건조효모(셀레늄) |
| d-α-토코페롤 / D-알파-토코페롤(고시형) | d-α-토코페롤 (천연형) |

원본에 괄호가 HTML 엔티티로 남은 행(`건조효모&#40;아연함유&#41;`)까지 되살려 읽는다.

## 3. 영양원으로 세지 않은 것

이름에 영양성분이 들어 있지만 그 영양성분의 영양원이 아닌 원료다. 걸러내지 않으면
"마그네슘 원료 1위가 활택제" 가 되어 통계가 통째로 못 쓰게 된다.

| 원료 | 원본 건수 | 왜 뺐는가 |
|---|---|---|
| 스테아린산마그네슘 | 15,251 | 활택제. 마그네슘 영양원이 아니다 |
| 카복시메틸셀룰로스칼슘 | 5,938 | 붕해제 |
| 스테아린산칼슘 | 33 | 고결방지제 |
| 제1(제일)인산칼슘 | 1 | 산도조절제·팽창제. 공전 칼슘 기원이 아니다 |
| 피로인산칼슘 | 2 | 팽창제 |
| 니코틴산아미드 모노뉴클레오타이드(NMN) | 58 | 나이아신 영양원으로 신고된 원료가 아니다 |
| 용성비타민P | 43 | 플라보노이드. 공전 영양성분이 아니다 |
| 비타민나무(산자나무) 열매 | 6 | 식물명. 비타민 원료가 아니다 |

반대로 **다른 영양성분의 염으로 옮겨 센 것**:

| 원료 | 원본 건수 | 어디로 |
|---|---|---|
| 판토텐산칼슘 | 6,577 | 칼슘이 아니라 **판토텐산(비타민B5)** |
| L-아스코브산칼슘 | 68 | 칼슘이 아니라 **비타민C** |

판토텐산칼슘은 열·습도에 취약한 판토텐산의 안정성을 높이려 칼슘염을 결합한 원료다.
분자 구조상 칼슘 비중이 8%대에 불과하고, 칼슘을 보충하려고 이 원료를 넣는 제조사는 없다.
품목제조신고서의 영양·기능정보에도 판토텐산 함량만 기능성분으로 잡히고 칼슘은 표시되지
않으므로 B5 로 집계하는 것이 데이터 정합성에 맞다.

### 인산칼슘 · 탄산칼슘 — 제품마다 갈린다

둘 다 공전 칼슘 기원이면서 부형제로도 쓰인다. 이름만으로는 가릴 수 없으므로 **제품의
영양·기능정보 표기 유무**로 나눈다.

| 조건 | 판정 |
|---|---|
| 기준규격(`STDR_STND`)에 칼슘 함량이 질량으로 잡힌다 | **칼슘 영양원** |
| 칼슘 함량 표기가 없다 | **부형제** — 영양원 집계에서 뺀다 |

'확인' 같은 정성 규격은 함량 표시로 보지 않는다. 원료마다 부형제로 쓰이는 방식이 다르다.

- **제2·제3인산칼슘** — 분말 유동성을 높이고 뭉침을 막는 고결방지제, 타정용 부형제로
  극소량 처방하는 쪽이 더 많다
- **탄산칼슘** — 칼슘 함량이 높아 주원료로 쓰면 원재료명 최상단에 온다. 칼슘 표기가 없고
  끝자락에 적힌 건은 이산화티타늄 대체용 백색 필름코팅제나 타정 충전제로 쓴 경우다

실측하면 이 갈림이 실제로 필요하다.

| 원료 | 칼슘 함량 표기 있음 | 표기 없음 | 원재료명 내 평균 위치 (있음 / 없음) |
|---|---|---|---|
| 인산칼슘(제2·제3) | 152 | 592 | 0.25 / 0.64 |
| 탄산칼슘 | 502 | 679 | 0.24 / 0.60 |

두 원료를 전부 영양원으로 세면 칼슘 집계가 10,381건이 되고, 표기 있는 것만 세면
**9,109건**이다. 표기 없는 쪽은 위치 분포가 원재료명 끝자락에 몰려 있어 부형제 용도라는
걸 뒷받침한다.

부형제로 뺀 건은 조용히 사라지지 않는다. 제품 상세 패널에 이렇게 남는다.

> 부형제로 판정해 영양원에서 뺀 원료: 탄산칼슘 (부형제 · 칼슘 함량 표시 없음)

같은 판정을 다른 원료에도 재 볼 수 있다.

```bash
node scripts/probe-declared-nutrient.mjs '탄산칼슘' '칼슘'
```

### 괄호 안을 언제 읽는가

괄호 안에는 담체·산화방지제가 함께 적혀 있다. 그래서 **괄호 앞(머리)이 원료 이름을
가리키면 괄호 안은 보지 않는다.**

- `비타민 B12 혼합제제(비타민B12 1%, 제이인산칼슘 99%)` → 비타민B12만. 제이인산칼슘은 담체다
- `정제어유(정제어유 99.9%, 비타민E 0.1%)` → 판정 없음. 이 비타민E는 산화방지 목적이다
- `건조효모(셀렌함유)` → 머리가 '건조효모' 뿐이므로 괄호를 읽어 셀레늄으로 판정

**알려진 한계**: 이 규칙 때문에 `해조분말(해조칼슘)` 8건 · `난각분말(유기농난각칼슘)` 5건
같은 표기는 칼슘으로 세지 않는다(합계 17건). 규칙을 풀면 위의 산화방지제까지 다시
새기 때문에 그대로 두었다.
