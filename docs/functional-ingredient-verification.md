# 기능성 원료 조회 자료 검증

검토일: 2026-09-05. 입력: 사용자가 제공한 `기능성 원료.csv`(78개 데이터 행).

## 범위

- 원문은 `src/data/functionalIngredients.source.json`에 보존했다. 참고 문단은 데이터나 지시사항으로 취급하지 않았다.
- 조회 자료는 `src/data/functionalIngredients.json`의 70개 항목이며 `sourceIds`로 원문 78개 행을 중복 없이 추적한다.
- 고시형 34개, 개별인정형 조회 항목 30개(공식 인정 사례 51개), 인정 원료를 특정하지 못한 항목 6개다. 식약처 전체 목록을 수록한 자료는 아니다.
- 식사 포함 권장량인 KDRIs는 검증 대상과 화면의 일일섭취량에서 제외했다. 원문에 있던 독점기간 등 부연 설명도 채택하지 않았다.

## 공식 자료

1. [식품분야 공전 온라인 서비스 – 건강기능식품공전](https://various.foodsafetykorea.go.kr/fsd/#/ext/Document/FF), 제2026-43호(2026-06-11). 제3의 영양성분 10개 및 기능성 원료 24개 항목 PDF에서 기준 성분, 기능성, 일일섭취량을 직접 확인했다. 항목별 PDF 주소는 각 레코드의 `sourceUrl`에 있다.
2. [식품안전나라 건강기능식품 원료별 정보](https://www.foodsafetykorea.go.kr/portal/board/board.do?menu_grp=MENU_NEW01&menu_no=2660). 공개 검색의 655개 게시물 목록을 확인하고, 첨부 원료와 관련된 개별인정 상세 게시물을 읽었다. 표시한 인정번호·업체·기능성·섭취량은 해당 상세의 조합을 유지했다. 제목에 여러 인정번호가 있더라도 본문에서 검증한 번호만 사용했다.
3. [제2026-43호 개정고시](https://impfood.mfds.go.kr/CFBDD02F02?active=00049&cntntsMngId1=00049&cntntsMngId2=00049&cntntsSn=659791). 공전 PDF의 개별 시행일을 확인해 2027-01-01 시행 예정 기준을 현재 기준에 섞지 않았다.

## 주요 정정

- 비타민 D: 1.5~10 → 3~10 μg. 비타민 A: RE → RAE. 철: 미기재 → 3.6~15 mg.
- 글루코사민: 1.5~2 g → 염산염 또는 황산염으로서 1.5 g. 가르시니아: HCA 750~2,800 → 750~1,500 mg. 알로에 겔: 총다당체 100~420 → 110~420 mg.
- 저분자콜라겐펩타이드는 개별인정 사례로, 빌베리·쏘팔메토·난소화성말토덱스트린은 고시형 공전 기준으로 정리했다.
- 대두이소플라본은 현재 24~27 mg / 2027년 37~45 mg, 헤마토코쿠스는 현재 4~12 mg / 2027년 6~12 mg, 레시틴은 현재 1.2~18 g / 2027년 18 g, 뮤코다당·단백은 현재 1.2~1.5 g / 2027년 2 g이다.
- 홍삼·EPA/DHA·NAG·히알루론산 등은 기능성별 기준을 나누었다. 프로폴리스 구강 항균은 직접 접촉 형태이며 섭취량 적용 예외를 표시했다.
- 개별인정형은 통칭의 보편적 섭취량을 만들지 않았다. 보스웰리아, 아쉬아간다, 석류, GABA 등은 각 인정번호의 기능성·기준 성분·섭취량을 함께 제시한다. 크릴오일 중량을 EPA+DHA 함량으로 바꾸지 않았다.
- mg 변환은 질량 단위 g→mg만 적용했다. μg, μg RAE, CFU는 유지하며, 추출물·기능성분·지표성분의 기준을 바꾸지 않았다.
- 난소화성 전분, 차가버섯, 아가리쿠스, 포괄적인 유산균 발효물·밀크씨슬+강황 복합·프로바이오틱스 복합은 인정 원료를 특정할 수 없어 `unresolved`로 두고 공식 섭취량을 제시하지 않았다. 검색 결과 부재를 미인정의 증거로 단정하지 않았다.
- CSV의 '개별' 통칭만 있고 별도 인정번호가 없는 밀크씨슬·가르시니아·카테킨·프로폴리스·프락토올리고당은 공전 항목에 함께 연결하고 그 한계를 설명했다. MBP는 유단백추출물의 관련 인정 사례를 보여주되 보유 원료와 동일한지는 확인이 필요하다고 명시했다.

## 구현 경계

원료 자료는 탭을 처음 열 때 별도 코드로 불러온다. 제품 데이터 API·저장·인증·수입·필터·통계·내보내기·기존 성분 통합 로직은 변경하지 않았다. 상담 화면을 숨겨 탭 이동 전 검색 조건과 페이지 상태를 유지한다. 제품 상세 패널의 키보드 처리기는 원료 탭에서 작동하지 않는다.

정적 검증 자료이며 자동 갱신 기능은 없다. 화면에 검토일과 자료 범위, 시행 예정 사항 및 원문 링크를 제공한다. 개별 원료 사용 가능 여부는 공급 원료와 해당 인정서의 동일성에 달려 있다.

## 검증 결과

- 원료 자료·검색 및 기존 제품 검색·페이지·1알 중량·스냅샷 관련 자동 검사 25개 통과. 수정 파일 정적 검사와 운영용 빌드 통과.
- 운영용 로컬 화면에서 분류·검색·인정번호별 섭취량·상세·시행 예정 변경·미확정 항목·페이지 이동을 확인했다. 검증된 원료의 기능성 검색에 CSV의 잘못된 기능성 문구가 포함되지 않는 것도 확인했다.
- 기존 45,970개 제품 표시와 비타민 C 조건의 5,014개 결과, 50개씩 페이지 이동을 확인했다. 탭 왕복 시 기존 검색 조건·페이지·선택 제품이 유지되며 원료 탭에서는 제품 상세 패널이 숨겨진다.
- 운영 배포는 사용자 승인 전까지 진행하지 않는다.
