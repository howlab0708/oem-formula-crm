# UX/UI 수정 검토 · 2026-09-11

검토 주소: http://127.0.0.1:3001/
상태: 로컬 수정 완료, 사용자 검토 대기, 배포하지 않음.

## 요청 반영

1. 검색 영역을 **검색필터** 대제목으로 묶고 즐겨찾기를 같은 영역에 배치했습니다.
2. 길게 펼쳐지던 선택 목록은 **주원료·제형 / 부원료 포함·제외 / 원료 형태·기원 / 함량·규격·제조원** 네 묶음으로 줄였습니다. 상세 목록은 팝업 안에서 검색하고 선택합니다. 목록의 초기 표시 수와 한 번에 추가로 표시하는 수를 제한했으며 나머지 옵션도 계속 조회할 수 있습니다.
3. 이전 항목·전체 조건 초기화 버튼 영역을 **검색 히스토리**로 바꿨습니다. 적용 중 조건과 직전 검색 요약을 표시하고, 팝업에서 이전 조건 전체를 확인하여 복원합니다. 복원·조건 비우기 이후에도 직전 조건을 최근 20개 기록에서 다시 찾을 수 있습니다.
4. **CSV 데이터 연동**을 검색필터 위의 별도 카드로 분리했습니다. **CSV 파일 선택** 버튼으로 파일 선택창을 바로 열고, 인코딩·처리 상태 등 기존 기능도 카드 안에 표시합니다.
5. 즐겨찾기는 최근 목록을 짧게 표시하고 전체 관리와 현재 검색 저장은 팝업으로 분리했습니다. 저장된 이름을 누르면 조건 내용을 확인한 뒤 적용합니다.
6. 고객 배포용 PDF 영역을 **포장 단위·제품 정보 위**로 이동했습니다.
7. 메모를 **회사 정보 바로 아래**로 이동하고 표시 이름을 **메모**로 바꿨습니다.
8. 저장된 배합비·원료단가·레퍼런스 상세·검색 상세·내보내기 설정/미리보기에 제목이 있는 팝업과 어두운 배경을 적용했습니다. 닫기 버튼, Esc, 배경 클릭으로 닫을 수 있습니다.
9. 배합 설계의 수량 구간별 단가 설명을 **고객사에게 제공하는 할인 비율을 구간마다 적습니다.**로 교체했습니다.

## 확인한 동작

- 수정 파일 ESLint, TypeScript 검사, 프로덕션 빌드, diff 공백 검사 통과.
- 히스토리 테스트: 복원 전 조건 보존, 조건 비우기 복원, 연속 검색어 입력 묶기, 변경 없는 요청 및 잘못된 인덱스 처리, 최근 20개 제한.
- 예시 레퍼런스: 비타민C 7건 → 비타민C·아연·정제 2건 → 비타민C 기록 복원 7건.
- 즐겨찾기 미리보기와 적용: 비타민C·정제 4건.
- 저장된 배합비 팝업 → 회사명·제목·메모·시트 반영 및 닫기.
- 견적 버전 선택 → 해당 시트 반영 및 팝업 닫기.
- 원료단가 팝업의 배경 클릭 닫기.
- 검색필터와 CSV 카드의 분리 배치, CSV 파일 선택 버튼의 파일 선택창 호출 확인. 파일 업로드는 실행하지 않음.
- 수량 구간별 단가에 요청한 할인 설명이 표시되고 이전 표현이 없는 것을 확인.
- 고객용 PDF 2쪽 미리보기 렌더링, 검색 내보내기 미리보기와 설정 팝업 복귀.
- 레퍼런스 상세 팝업 안에서 다음 제품으로 전환.
- 데스크톱 및 390×844 모바일 너비에서 팝업 확인. 모바일 결과 보기는 필터 패널까지 닫고 결과를 표시.
- 브라우저 콘솔 경고·오류 없음.

## 검토 환경과 수정 범위

검토 화면은 앱의 예시 레퍼런스 41건과 별도의 검증용 즐겨찾기·배합비 응답을 사용합니다. 로컬 운영 DB 연결은 없으며, 검토 서버의 저장·삭제·CSV 업로드 요청은 차단되어 있습니다. 실제 운영 DB 저장과 CSV 업로드는 이번 검증에서 실행하지 않았습니다.

배합 계산식, 검색 매칭 규칙, CSV 파서, 서버 API·저장 로직, 노트 탭은 수정하지 않았습니다. 기능성 원료 탭은 후속 요청에 따라 분류·인정상태와 근거 표시를 재검토했습니다. 작업 시작 전에 존재하던 globals.css, proxy.ts, 소개 페이지 및 데이터 관련 미커밋 변경은 그대로 보존했습니다.

검토 순서: 검색필터 묶음과 즐겨찾기 → 복수 성분 선택 후 검색 히스토리 → 배합 설계 상단 메모/PDF 위치 → 저장된 배합비·원료단가 팝업.

즐겨찾기 별표를 회색 윤곽선 북마크로 교체했습니다. [기능성 원료 전체 재검토 결과](functional-ingredient-review-20260911.md)에 621개 항목의 검토 범위와 분류, 수정 근거를 정리했습니다. 후속 요청에 따라 인정 종료·통합 38개, 과거 인정 9개, 미등재·자료 불일치 12개를 조회 데이터와 분류 버튼에서 제거했습니다. 업무 화면은 전체 562개·고시형 96개·개별인정형 466개만 제공합니다.
